Engine Architecture:
100% Procedural First-Person ASCII Raycaster with DDA, Bayer ordered dithering, and pre-rendered Glyph Atlas offscreen stamping.

Audio Architecture:
100% Procedural Web Audio API sound generator. Zero external samples, zero external network requests.

Terms and conditions

Photosensitivity warning:
This game contains flickering light effects, flame oscillation, and live memory glitch flashes. If you experience dizziness or seizures, discontinue immediately.

Local data storage:
Game progress is stored strictly on your local device. In accordance with permadeath rules, losing all three lives permanently erases the active save file.
